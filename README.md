# Polling Backend

Это backend-сервер для системы опроса (polling), написанный на TypeScript с использованием Express. Сервер генерирует случайные данные о непрочитанных сообщениях и предоставляет API endpoint для их получения.

## Функциональность

- Генерация случайного количества непрочитанных сообщений (от 0 до 4)
- Каждое сообщение содержит:
  - Уникальный ID (UUID)
  - Отправителя (случайный email)
  - Тему (случайное предложение)
  - Тело сообщения (случайный параграф)
  - Время получения (временная метка)
- API endpoint `/messages/unread` для получения списка непрочитанных сообщений

## Зависимости

- `express`: веб-фреймворк для Node.js
- `@faker-js/faker`: генерация случайных данных
- `uuid`: генерация уникальных идентификаторов
- `typescript`: язык программирования с типизацией
- `ts-node`: выполнение TypeScript файлов

## Установка

1. Убедитесь, что у вас установлен Node.js
2. Склонируйте репозиторий
3. Выполните установку зависимостей:

```bash
npm install
```

## Запуск

### Компиляция TypeScript:

```bash
npm run build
```

### Запуск скомпилированного сервера:

```bash
npm start
```

### Запуск в режиме разработки (с ts-node):

```bash
npm run dev
```

Сервер будет запущен на порту 3000, и endpoint будет доступен по адресу: http://localhost:3000/messages/unread

## API

### GET /messages/unread

Возвращает JSON с информацией о непрочитанных сообщениях:

```json
{
  "status": "ok",
  "timestamp": 1234567890,
  "messages": [
    {
      "id": "uuid-v4-string",
      "from": "email@example.com",
      "subject": "Тема сообщения",
      "body": "Текст сообщения",
      "received": 1234567890
    }
  ]
}
```
